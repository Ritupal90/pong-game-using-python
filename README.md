
# Pong Game in Python

This is a simple implementation of the classic **Pong** game, created using **Python** and the **Pygame** library. It allows two players to compete against each other in a fast-paced game of Pong, controlling paddles to hit the ball and score points.

## Features

- **Two-player mode**: Play against a friend locally.
- **Paddle movement**: Players control paddles using the keyboard (Up/Down arrows for one player, W/S keys for the other).
- **Scoring system**: Points are scored when the ball passes the opponent's paddle.
- **Game over screen**: When one player reaches the target score, the game ends with a winner.

## How to Play

1. **Player 1**: Use the **W** and **S** keys to move the paddle up and down.
2. **Player 2**: Use the **Up Arrow** and **Down Arrow** keys to control the paddle.
3. The ball bounces back and forth between the paddles.
4. Score points by getting the ball past your opponent's paddle.
5. The game ends when a player reaches a predefined score limit (e.g., 5 points).

## Requirements

Make sure you have Python installed on your computer. This game also uses **Pygame**, which you can install using the following command:

```bash
pip install pygame
```

## Installation

To run the game, follow these steps:

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/your-username/pong-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pong-game
   ```

3. Install the required dependencies:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python pong_game.py
   ```

   After running the command, the game window will appear, and you can start playing with a friend!

## Game Controls

- **Player 1**:
  - Move paddle **up**: **W**
  - Move paddle **down**: **S**
  
- **Player 2**:
  - Move paddle **up**: **Up Arrow**
  - Move paddle **down**: **Down Arrow**

## Customization

Feel free to modify the following settings in the code:

- **Ball speed**: Adjust the speed of the ball to make the game faster or slower.
- **Paddle size**: Change the height and width of the paddles to make them bigger or smaller.
- **Score limit**: Adjust the score needed to win the game (default: 5 points).
